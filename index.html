🎮 About Digital Gaming Hub

Digital Gaming Hub is a browser-based gaming platform built as a B.Tech college project at Parul University. Players can login with Google, play 6 different games, earn points and compete on the leaderboard. No downloads, no installs — just open and play!

✨ Features

  • 6 fully working games — Snake, Tic Tac Toe (with AI), Memory Match, Quiz Arena, Minesweeper, Slide Puzzle
  • Real Google Sign-In powered by Firebase
  • AI opponent in Tic Tac Toe using Minimax algorithm
  • Live Leaderboard with score tracking
  • Sound effects in all games
  • Works on mobile and desktop
  • 100% Free — no ads, no payments

🛠️ Technologies Used

HTML5 CSS3 JavaScript Canvas API Firebase Auth Google Sign-In LocalStorage Minimax AI GitHub Pages Responsive Design
