🎮 About Digital Gaming Hub

Digital Gaming Hub is a college web project — a browser-based gaming platform where students can play, compete, and have fun. Built with pure HTML, CSS, and JavaScript — no downloads, no installs. Just open and play!

✨ Features

  • 6 fully working games in one page
  • Google Sign-In + Email Login
  • Live Leaderboard with score tracking
  • Works on mobile and desktop
  • 100% Free — no ads, no payments

🛠️ Technologies Used

HTML5CSS3JavaScript Canvas APILocalStorageGoogle Auth Responsive Design
